## WEEKLY CONTENT PRODUCTION SCHEDULE

### MONDAY (Planning & Strategy - 2 hours)
**Week Review & Planning**

- [ ] Review previous week's analytics
  - [ ] Blog post traffic
  - [ ] Social media engagement
  - [ ] Consultation requests
  - [ ] Top performing content
  - [ ] Underperforming content

- [ ] Plan week's content
  - [ ] Check content calendar for this week
  - [ ] Review upcoming seasonal opportunities
  - [ ] Note any breaking legal news to address
  - [ ] Assign responsibilities (if team)

- [ ] Blog Post Outline
  - [ ] Select topic from calendar
  - [ ] Research keywords
  - [ ] Create detailed outline
  - [ ] Identify needed resources (statutes, data, images)

- [ ] Social Media Planning
  - [ ] Theme for each day
  - [ ] Identify content pillars to hit
  - [ ] Note any blog promotion needed
  - [ ] List graphics needed

- [ ] Email Planning
  - [ ] Weekly digest topic
  - [ ] Featured blog post
  - [ ] Call-to-action

---

### TUESDAY (Content Creation - 4-5 hours)
**Writing Day**

- [ ] Blog Post Writing

  - [ ] Write main sections (follow outline)
  - [ ] Include data/statistics
  - [ ] Add personal insights/law enforcement perspective
  - [ ] Write conclusion and CTA
  - [ ] First draft complete

- [ ] Social Media Content Creation

  - [ ] Write captions with hashtags

- [ ] Video Script (if video week)
  - [ ] Write intro hook
  - [ ] Outline main points
  - [ ] Write talking points (not full script)
  - [ ] Plan b-roll/graphics needs
  - [ ] Write outro and CTA

  - [ ] Self-edit for clarity and flow

- [ ] Graphic Design
  - [ ] Blog featured image

  - [ ] Data visualization (if applicable)

- [ ] Video Recording (if applicable)

  - [ ] Record A-roll (talking head)
  - [ ] Record B-roll (if needed)

- [ ] Social Media Drafts
  - [ ] Draft Thursday-Sunday posts
  - [ ] Finalize all captions
  - [ ] Assign graphics to posts

  - [ ] Add alt text to images

- [ ] Publish Blog Post
  - [ ] Set publish time (typically 9 AM)

  - [ ] Submit to Google Search Console
  - [ ] Share internally with team

- [ ] Social Media Promotion

  - [ ] LinkedIn: Professional angle post
  - [ ] Twitter: Thread breakdown of blog
  - [ ] Instagram Stories: 3-5 frames promoting post

- [ ] YouTube Video (if scheduled)
  - [ ] Upload video
  - [ ] Optimize title, description, tags
  - [ ] Add timestamps
  - [ ] Create custom thumbnail
  - [ ] Add to appropriate playlists
  - [ ] Schedule or publish
  - [ ] Promote on social media

- [ ] Email Newsletter Prep
  - [ ] Add blog post to newsletter
  - [ ] Write preview copy
  - [ ] Add CTA buttons
  - [ ] Preview email on mobile

## BLOG POST PRODUCTION CHECKLIST

### RESEARCH & PLANNING
- [ ] Topic selected from content calendar
- [ ] Keyword research completed
  - [ ] Primary keyword identified
  - [ ] Secondary keywords (3-5)
  - [ ] Search volume checked
  - [ ] Competition analyzed
- [ ] Outline created
- [ ] Word count target set
- [ ] Publish date scheduled
- [ ] Resources gathered
  - [ ] Florida Statutes to cite
  - [ ] Case law if applicable
  - [ ] Data/statistics sources
  - [ ] Expert quotes or sources
  - [ ] Related blog posts to link

### WRITING
- [ ] Introduction written (hook, stakes, promise)
- [ ] All main sections completed
- [ ] Personal insights added (law enforcement perspective)
- [ ] Data/statistics included with citations
- [ ] Examples and case studies added
- [ ] Conclusion written
- [ ] Strong CTA included
- [ ] Target word count met
- [ ] Headers properly structured (H2, H3, H4)

### SEO OPTIMIZATION
- [ ] Primary keyword in:
  - [ ] Title (first 60 characters)
  - [ ] First paragraph
  - [ ] At least 2 H2 headings
  - [ ] Naturally throughout (1-2% density)
  - [ ] Meta description
  - [ ] URL slug
- [ ] Secondary keywords naturally distributed
- [ ] Internal links added (5-10)
- [ ] External links to authoritative sources (3-5)
- [ ] Alt text on all images
- [ ] Featured image optimized
  - [ ] File size under 200KB
  - [ ] Descriptive file name
  - [ ] Alt text with keyword

### EDITING & PROOFREADING
- [ ] Grammar and spelling checked (Grammarly)
- [ ] Readability score acceptable (Hemingway 8-10)
- [ ] Sentence variety (short, medium, long)
- [ ] Paragraph length (3-5 sentences)
- [ ] Active voice predominant
- [ ] Legal jargon explained
- [ ] Tone consistent (professional but approachable)
- [ ] All facts verified
- [ ] Citations accurate

### FORMATTING & DESIGN
- [ ] Headers properly formatted
- [ ] Bullet points and numbered lists used
- [ ] Bold and italics for emphasis
- [ ] Blockquotes for important callouts
- [ ] Tables or comparison charts (if applicable)
- [ ] Featured image created
- [ ] In-content images (2-4)
- [ ] Infographics or data visualizations
- [ ] Mobile-friendly formatting

### PRE-PUBLISH
- [ ] Preview on website
- [ ] Check mobile view
- [ ] All links tested
- [ ] Images display properly
- [ ] CTA buttons functional
- [ ] Contact forms working
- [ ] Categories/tags assigned
- [ ] Author bio included
- [ ] Related posts widget configured

### PUBLISH
- [ ] Published at optimal time (9-11 AM Tuesday-Thursday)
- [ ] Shared on all social media platforms
- [ ] Submitted to Google Search Console
- [ ] Added to email newsletter
- [ ] Pinged relevant people (if mentions)
- [ ] Updated internal linking structure

### POST-PUBLISH
- [ ] Monitor comments (respond within 24 hours)
- [ ] Track initial traffic
- [ ] Note what's working
- [ ] Repurpose into social content
- [ ] Add to content library/database
- [ ] Schedule evergreen promotion

## SOCIAL MEDIA POST CHECKLIST

### CONTENT CREATION
- [ ] Topic/theme aligns with content pillar
- [ ] Message is clear and focused
- [ ] Hook/opening line grabs attention
- [ ] Value provided to audience
- [ ] CTA included (soft, medium, or strong)
- [ ] Hashtags researched and added
  - [ ] Platform-appropriate number
  - [ ] Mix of popular and niche
  - [ ] Branded hashtags included
- [ ] Brand voice consistent
- [ ] Proofread for errors

### VISUAL ELEMENTS
- [ ] Graphic created or selected
- [ ] Image dimensions correct for platform
- [ ] File size optimized
- [ ] Brand colors used
- [ ] Logo included (if appropriate)
- [ ] Text overlay readable on mobile
- [ ] Alt text added (accessibility)
- [ ] Consistent visual style

### PLATFORM-SPECIFIC
**Facebook:**
- [ ] Post length: 40-80 characters for link posts, 100-250 for text posts
- [ ] Link preview displays correctly
- [ ] Tagged relevant pages (if applicable)
- [ ] Location added (Orlando, FL)

**Instagram:**
- [ ] Image is high quality (1080x1080 or 1080x1350)
- [ ] Caption is engaging (first line critical)
- [ ] 15-30 hashtags used
- [ ] Location tag added
- [ ] Accounts tagged (if applicable)
- [ ] Story also created to promote

**LinkedIn:**
- [ ] Professional tone maintained
- [ ] Industry hashtags included
- [ ] Document/carousel upload (if applicable)
- [ ] Tagged relevant connections

**Twitter:**
- [ ] Under 280 characters (ideally 71-100 for retweets)
- [ ] Thread planned if multi-part
- [ ] 1-2 hashtags max
- [ ] @mentions used strategically

**YouTube:**
- [ ] Title optimized (under 60 chars, keyword front-loaded)
- [ ] Description detailed (200+ words)
- [ ] Timestamps added
- [ ] Tags added (10-15 relevant tags)
- [ ] Custom thumbnail uploaded
- [ ] End screen configured
- [ ] Cards added
- [ ] Added to playlist

### SCHEDULING
- [ ] Optimal posting time selected
  - [ ] Facebook: 9-11 AM, 1-3 PM
  - [ ] Instagram: 11 AM, 2 PM, 7-9 PM
  - [ ] LinkedIn: 8-10 AM Tues-Thurs
  - [ ] Twitter: 9 AM, 12 PM, 5 PM
- [ ] Scheduled in tool (Meta Business Suite, Hootsuite, etc.)
- [ ] Double-checked date/time
- [ ] Content calendar updated

### POST-PUBLISH
- [ ] Monitor for first 2 hours (engagement window)
- [ ] Respond to comments promptly
- [ ] Engage with shares/retweets
- [ ] Track performance after 24 hours
- [ ] Note insights for future posts

- [ ] Graphics/overlays planned
- [ ] Location selected
- [ ] Wardrobe selected (professional, solid colors)

- [ ] Footage imported
- [ ] Best takes selected
- [ ] Video edited
  - [ ] Intro sequence (branded)
  - [ ] Jump cuts for pacing
  - [ ] B-roll inserted
  - [ ] Lower thirds added (name, title)
  - [ ] Graphics/text overlays
  - [ ] Background music (royalty-free, low volume)
  - [ ] Outro with CTA
- [ ] Audio edited
  - [ ] Levels normalized
  - [ ] Background noise reduced
  - [ ] EQ applied
- [ ] Color correction applied
- [ ] Transitions smooth
- [ ] Length optimized (8-15 min ideal, under 20 max)

- [ ] 1280 x 720 px

- [ ] Contrasting colors

- [ ] Text overlay (3-5 words max)

### UPLOAD & OPTIMIZATION

  - [ ] Links to blog, website, contact
  - [ ] Call to action
  - [ ] Disclaimer if needed
- [ ] Tags added (10-15 relevant)
- [ ] Category selected
- [ ] Thumbnail uploaded
- [ ] End screen configured (last 20 seconds)
- [ ] Cards added at relevant moments
- [ ] Subtitles/closed captions reviewed (auto-generated)
- [ ] Added to relevant playlist(s)

### PROMOTION
- [ ] Shared on all social platforms
- [ ] Embedded in related blog post
- [ ] Added to email newsletter

## EMERGENCY CONTENT PROTOCOL

### BREAKING NEWS OR URGENT TOPIC

**When Florida passes major new law or high-profile case emerges:**

1. **Immediate Response (Within 24 hours):**
   - [ ] Draft quick social media post
   - [ ] Post to Facebook, Instagram, LinkedIn, Twitter
   - [ ] Basic facts + "full analysis coming soon"
   - [ ] Monitor engagement and questions

2. **Short-Form Content (Within 48 hours):**
   - [ ] Write 800-1,200 word blog post
   - [ ] Quick analysis of what it means
   - [ ] How it affects clients
   - [ ] CTA for consultations
   - [ ] Promote heavily on social

3. **Long-Form Content (Within 1 week):**
   - [ ] Comprehensive 2,000+ word analysis
   - [ ] Data/statistics if available
   - [ ] Detailed implications
   - [ ] Update short-form post with link
   - [ ] Create video if high interest

4. **Ongoing Updates:**
   - [ ] Monitor developments
   - [ ] Update blog post as needed
   - [ ] Continue social media discussion
   - [ ] Position as go-to expert on topic

## CONTENT REPURPOSING GUIDE

### ONE BLOG POST → 15+ PIECES OF CONTENT

**From a single 2,500-word blog post, create:**

1. **Social Media (10-12 posts):**
   - 3 Facebook posts (opening hook, key stat, case example)
   - 2 Instagram feed posts (key takeaway, graphic quote)
   - 1 Instagram carousel (5-7 slides of main points)
   - 2 LinkedIn posts (professional angle, industry insight)
   - 3 Twitter threads (main points breakdown)
   - 5+ Instagram Stories (chapter-by-chapter)

2. **Video Content (2-3 videos):**
   - 1 YouTube video (8-15 min full topic)
   - 2 Instagram Reels (30-60 sec quick tips)
   - 1 YouTube Short (under 60 sec hook)

3. **Email Content (2 emails):**
   - 1 Feature in weekly newsletter
   - 1 Dedicated email to segment

4. **Other Formats:**
   - 1 Downloadable PDF checklist
   - 1 Infographic summarizing key points
   - 1 Quote graphic for Pinterest
   - LinkedIn article (condensed version)

**Total from one blog post: 18-20 pieces of content**

## FINAL REMINDERS

### CONSISTENCY IS KEY
- Stick to the schedule
- Even during slow weeks, maintain presence
- Quality over quantity, but frequency matters
- Batch content when possible to stay ahead

### ENGAGEMENT IS ESSENTIAL
- Respond to every comment (even negative ones professionally)
- Answer DMs within 24 hours
- Engage with followers' content
- Build community, not just audience

### MEASURE EVERYTHING
- Track all KPIs weekly
- Review monthly
- Adjust based on data, not assumptions
- Document what works

### ALWAYS BE LEARNING
- Stay updated on SEO best practices
- Monitor algorithm changes
- Watch competitors
- Attend webinars/courses on content marketing
- Adapt and evolve strategy

**This workflow is designed to be systematic yet flexible. Adjust as needed based on your resources, results, and changing priorities. The key is consistency, quality, and continuous improvement.**

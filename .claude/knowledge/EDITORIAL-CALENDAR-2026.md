## SEO Best Practices Checklist

For each post:

- [ ] Use target keyword in H1 title
- [ ] Include keyword in first 100 words
- [ ] Add canonical URL and og:* tags
- [ ] Include internal links to related posts
- [ ] Add Article schema markup (use scripts/add_blog_schema.py)
- [ ] Add BreadcrumbList schema (use scripts/add_breadcrumb_schema.py)
- [ ] Update blog.html listing page
- [ ] Update sitemap.xml with new URL
- [ ] Include CTA for free consultation

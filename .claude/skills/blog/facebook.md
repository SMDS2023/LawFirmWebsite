# FACEBOOK — Post-Publish Distribution

Runs only on `live` posts. Output is **draft copy for Jeff to paste** (or to
post via a connected tool if he says so) — never post anywhere autonomously.

## Format

```
<Hook line — punchier remix of the post's hook, not the title>

<2-3 sentences: the story + the surprising authority detail. Written for a
neighbor, not a lawyer. No statute numbers unless they ARE the hook.>

<One-line takeaway or question that invites comments>

Read: https://lotterlaw.com/blog/<slug>/
```

## Rules

- Image: the post's og image (1200×630 — Facebook-native crop).
- Hashtags: at most 2, only if genuinely useful (#OrlandoDUI, #FloridaLaw).
  Never a hashtag wall.
- No client references beyond what the (already anonymized) post says.
- Advertising compliance: educational tone; no "best lawyer", no outcome
  promises; case-result language mirrors the post's disclaimer.
- Offer two variants: (A) story-led, (B) question-led. Jeff picks.

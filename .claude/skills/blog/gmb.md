# GMB — Google Business Profile Draft

Runs only on `live` posts. Output is a **draft for Jeff to paste** into the
Google Business Profile "Add update" flow.

## Format

```
TITLE (if using Offer/Event type — usually plain Update, no title)

150-300 words:
- Open with the local angle ("In Orange County traffic court..."), because
  GBP posts rank for "near me" intent.
- One concrete, useful takeaway a local reader can act on.
- Natural mentions of the locality (Orlando / Orange County / Seminole) and
  the practice area — no keyword stuffing.

Button: "Learn more" → https://lotterlaw.com/blog/<slug>/
Photo: assets/blog/<slug>-og.jpg
```

## Rules

- GBP truncates ~100 characters in the feed — the first sentence must stand
  alone.
- Strictly educational; GBP flags salesy legal content. No phone number in
  the body (the profile has it); the button carries the click.
- One post per blog article; don't recycle the Facebook copy verbatim —
  GBP wants local-informational, Facebook wants social-narrative.

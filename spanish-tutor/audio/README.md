# Audio Files

This directory contains pronunciation audio generated by Google Cloud Text-to-Speech API.

## Generation

Run `python generate-audio.py` from the spanish-tutor directory to generate all audio files.

**Prerequisites**:
1. Google Cloud project with Text-to-Speech API enabled
2. Service account JSON key file
3. Environment variable set: `GOOGLE_APPLICATION_CREDENTIALS=path/to/key.json`
4. Python package installed: `pip install google-cloud-texttospeech`

## Voice Configuration

- **Language**: Spanish (Spain) - `es-ES`
- **Voice**: Neural2-A (Female)
- **Speed**: 0.85x (slightly slower for learning)
- **Format**: MP3

## Naming Convention

- Vocabulary: `{lesson}-{word}.mp3` (e.g., `01-cero.mp3`)
- Phrases: `{lesson}-phrase-{number}.mp3` (e.g., `01-phrase-1.mp3`)
- Dialogue: `{lesson}-dialogue-{number}.mp3` (optional)

## File Count

Each lesson typically generates:
- 10-15 vocabulary files
- 4-6 phrase files
- **Total**: ~15-20 audio files per lesson
- **All 10 lessons**: ~150-200 audio files

## Placeholder Files

For testing without API access, create silent MP3 files:
```bash
# Windows (PowerShell)
for ($i=1; $i -le 12; $i++) {
  New-Item -ItemType File -Path "audio/01-vocab-$i.mp3" -Force
}
```

Production deployment should use real TTS-generated audio.
